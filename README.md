# tapflux

Tap identifiers and flux tokens for idempotent workflows.

**Site:** https://theworker02.github.io/tapflux/

## Install / run

```bash
git clone https://github.com/theworker02/tapflux.git
cd tapflux
node src/cli.js
node --test
```
